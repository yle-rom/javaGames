# javaGames

## MemoryGame
Start by running:
> java MemoryGame

The game asks for the 1st and 2nd position that you wish to reveal.
Then it 'unmasks' them,giving you time to memorize which number they hid.
The game ends either when you find all pairs or after 10 rounds.

## PrisonerGame
Start by running:
> java PrisonerGame

The game first asks if you wish to play between Human vs Computer or Human vs Human. 
The goal is to get as close to 31 without going overboard.
After selecting a number between 1 and 5, the opponent also selects one, with the cummulitive score being added to the player whose currently playing.
At the end of the round, you can either continue playing by pressing 'y' or you can stop by pressing 'n'

*Enjoy!*
